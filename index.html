MaintainX Design System

The single source of truth for MaintainX's visual identity — colors, logos, iconography, and the assets we use across product and marketing. Sourced directly from the Visual Library Figma file. If it's not here, it's not on-brand yet.

Logos

The MaintainX logo exists as a wordmark lockup (“MX-Logo”) and a standalone icon mark (“MX-Iso”), each in three colorways. Actual export files live in Figma — this environment can read Figma's structure but can't pull binary files out of it, so use the link below to export what you need.

MX-Logo (primary wordmark)

Full "MaintainX" wordmark with the X mark. Default lockup for headers, decks, and marketing.

Colorways: Black · White · W&B (swag only) — each with/without safe-area box
View & export in Figma ↗

MX-Iso (icon mark)

Standalone "X" icon for favicons, app icons, and tight spaces where the full wordmark won't fit.

Colorways: Black · White — each with/without safe-area box
View & export in Figma ↗

MX × Autodesk lockup

Co-branded partner lockup, used only for Autodesk-related integration collateral.

Colorways: Default · Black · White
View & export in Figma ↗
The "W&B" (white & color) wordmark variant is flagged in the source file as swag only — don't use it in product or marketing.

Icons

MaintainX uses the Streamline icon library as its base icon set — organized into 56 categories, likely 1,000+ icons in total. A legacy "Sharp Line Icons" set is kept in the file for reference on older screens but is no longer the default.

Product Compositions

Pre-built UI screenshot compositions (work orders, reporting, chat, parts, etc.) used across marketing pages and decks — organized as reusable parent components, then grouped "by use case" and "by industry" so you're not screenshotting the app from scratch every time.

By use case

Asset Management Preventive Maintenance Checklists & Inspections Facility Maintenance Parts Inventory Work Order Management Work Request Management AI-Powered Maintenance Operations Resource Planning IoT

By industry

Manufacturing Facilities Mgmt Food & Bev Hospitality Education & School Clubs & Associations Property Mgmt Fleet Mgmt
Before screenshotting a new one: check if a matching parent component already exists. If the copy is just different, make an instance of the existing component rather than a new one — see "How to use this library" on the Figma canvas for the full decision tree.

Full library: Figma → Product Compositions ↗
